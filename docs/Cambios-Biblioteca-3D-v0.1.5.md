# Cambios de Biblioteca 3D — v0.1.5

Fecha: 10 de septiembre de 2026.

- Cada tarjeta de animación incorpora un botón de carpeta junto al favorito.
- El botón selecciona primero la animación dentro de Biblioteca 3D.
- Después abre su carpeta real en el Explorador de Windows y deja seleccionado el FBX, GLB o GLTF exacto.
- El comando usa argumentos separados para admitir rutas con espacios correctamente.
- El botón evita propagar el clic, por lo que no altera favoritos ni dispara otra selección accidental.
- Los dos botones se acomodan verticalmente en vista compacta y horizontalmente en vista Lista y Grilla.
