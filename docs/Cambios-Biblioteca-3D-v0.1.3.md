# Cambios de Biblioteca 3D — v0.1.3

Fecha: 10 de septiembre de 2026.

- Se reemplazó la serie anterior por 24 miniaturas nuevas en estilo de maniquí blanco opaco sobre fondo negro.
- Cada pose conserva una lectura clara de la acción, las extremidades y los accesorios.
- Los archivos son WebP opacos de 256×256; la serie completa pesa 80.882 bytes.
- El distintivo FBX, GLB o GLTF continúa como capa independiente y refleja el formato real de cada archivo.
- Se retiró el filtro de brillo que oscurecía simultáneamente el fondo y el personaje.
- Las miniaturas v0.1.0 se conservaron como respaldo; la aplicación utiliza la serie v0.1.1.
- Se agregó Sharp únicamente como dependencia de desarrollo para la conversión y compresión de imágenes.
